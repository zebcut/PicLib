# Place database

Generated by `npm run places` (`scripts/build-places.sh`); don't edit by hand.

- `countries.tsv`: ISO country code, French name, English name (Unicode CLDR).
- `regions.tsv`: country code, region code, region name.
- `places.tsv`: populated places grouped by region (`>FR<tab>11` lines), then
  one line per place: latitude, longitude, name.

Source: [GeoNames](https://www.geonames.org), CC BY 4.0. See
`THIRD_PARTY_NOTICES.md`.
